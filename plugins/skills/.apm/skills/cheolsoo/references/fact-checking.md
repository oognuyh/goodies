# 모호성과 사실 확인

사실 확인을 요청받았거나 표현을 고치려면 공개 사실의 판별이 꼭 필요한 경우에만 참고한다. 표현만 다듬는 요청에서는 원문의 사실을 보존하고 검증하지 않았다는 주석을 자동으로 붙이지 않는다.

## 모호성 처리와 웹 검색

연도와 함께 나온 의무·금지·전면 적용, `모든·최초·유일·최신` 같은 보편·최상급 주장, 법령·인증·표준·제품 버전은 확인이 필요한 신호다. 명백한 충돌을 발견하면 조용히 바꾸지 말고 짧게 알린다. 웹 접근이 없거나 검색을 원하지 않으면 확정하지 않고 사용자에게 묻는다.

| 확인 대상 | 처리 |
| --- | --- |
| 공개 법령·표준·제품 사양·고유명사 | 웹 접근이 가능하면 공식 문서나 1차 자료에서 확인한다. |
| 현재 일정·정책·버전처럼 바뀔 수 있는 사실 | 최신 공식 출처를 확인하고 확인 시점을 기록한다. |
| 기밀·비공개 자료 | 외부 검색하지 않고 제공된 자료 안에서만 처리한다. |

웹 검색은 글쓰기·윤문의 범위를 넓히기 위한 조사가 아니다. 문장의 공개 사실이나 용어를 확정하는 데 필요한 최소 범위에서 수행한다.

- 공식 기관, 표준 원문, 제품 공식 문서를 우선한다.
- 검색 결과가 원문과 충돌하면 조용히 고치지 말고 충돌과 출처를 변경 요약에 밝힌다.
- 신뢰할 출처를 찾지 못하면 원문을 확정적으로 강화하지 않고 사용자에게 확인한다.
- 확인이 꼭 필요한데 웹 접근이 없거나 사용자가 검색을 원하지 않으면 원문을 단정적으로 강화하지 않고, 변경 요약에 확인이 필요한 부분을 짧게 알린다.
