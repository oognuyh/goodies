# ADR decisions

An ADR-worthy decision has meaningful reversal cost or impact, materially different real alternatives, and rationale future maintainers need. For a persisted format or event change, assess whether an older version can read newly written data and what rollback would require; an additive change can still have meaningful reversal cost. Apply the same three criteria rather than automatically requiring an ADR for every storage change. For each new ADR-worthy decision, obtain independent positions from at least two distinct native subagents, compare their evidence and dissent, decide as coordinator, and record an ADR with context, alternatives, choice, consequences, and verification obligations. Before marking a decision accepted or final, including in a draft ADR, wait for both actual responses and compare each counted stakeholder and attributed position with them; starting agents is not receiving their positions. Do not infer additional participants or consensus from your synthesis. Follow the project's ADR convention or use `docs/adr/YYYY-MM-DD-<slug>.md`. Record the decision before dependent implementation, including when the task ends with design. Reuse an applicable decision. If the required subagents or ADR are unavailable, leave dependent work blocked and continue independent work. Routine decisions do not need this process.

When original stakeholder responses need to be recoverable, determine before delegation whether the host can provide reopenable events when possible, then verify the actual event can be reopened. If this is unavailable or uncertain and the user and host permit writing and retaining evidence files at the chosen paths, you may give each stakeholder a distinct new permitted path outside the product target in its initial brief and ask it to write its complete response there and return the same body through the host. Compare each file with its complete actual return and inspect the host delegation and attribution separately; a file, digest or summary does not authenticate the author or prove independence. Honor read-only and content restrictions, existing files, links and host denials. A path check is not race-free isolation. If the original, comparison or provenance cannot be recovered, label summaries and report the affected assessment as unverified; do not launch duplicate stakeholders merely to retain a response.

If the user's boundary or the host prevents obtaining the required positions or recording the ADR, continue permitted investigation and report evidence, alternatives, and any clearly provisional recommendation. Identify the missing positions or record; a response is not a recorded ADR. Do not present the formal decision as complete or proceed with dependent work. An investigation or options-only request can reach its requested stopping point, but a request for the formal decision or ADR remains incomplete.
