# 개조식과 문서 형식

회의록·검토 메모·요약·실행 항목, 공문서의 항목 체계처럼 형식 선택이 중요한 한국어 글을 작성하거나 다듬을 때 참고한다. 기관 양식과 문서 목적을 우선한다.

## 개조식

국립국어원은 행정 용어 `개조식`을 `조목조목`으로 다듬어 제시하지만, 개조식 자체를 오류로 규정하지는 않는다. 회의록·검토 메모·요약·실행 항목처럼 빠른 탐색이 중요한 문서에서는 항목 구조를 살린다. 대국민 안내나 맥락 설명이 중요한 보고서는 완결된 서술문이 더 명확할 수 있다.

### 형식 선택

| 형식 | 알맞은 내용 | 편집 기준 |
| --- | --- | --- |
| 레이블형 | 기간, 대상, 방법, 문의처처럼 이름과 값이 짝을 이룸 | `신청 기간:`, `문의:`처럼 레이블을 유지하고 값의 구조를 맞춘다. |
| 명사·명사형 종결 | 내부 메모, 현황·조치 요약, 제목형 항목 | 조직 문체가 요구할 때 사용하되 긴 명사열에는 조사나 동사를 보탠다. |
| 완결 문장형 | 대국민 안내, 조건·인과·예외 설명, 외부 배포 보고서 | 주어·서술어와 문장 경계를 드러내고 필요한 온점을 쓴다. |

레이블과 설명 문장은 역할이 다르므로 문서 전체를 억지로 한 종결형으로 만들지 않는다. 다만 같은 역할·같은 깊이의 형제 항목은 표현과 종결 방식을 나란히 맞춘다.

### 항목과 문장 경계

- 항목 하나에는 중심 주장이나 행동 하나를 둔다. 조건·예외가 결론을 바꾸면 같은 항목 안에서 관계를 밝힌다.
- 담당자, 행동, 기한, 상태가 중요한 문서라면 항목 안에서 드러낸다.
- 명사나 명사형 어미로 끝나는 독립 문장이 연달아 나오면 온점과 띄어쓰기로 경계를 표시한다.
- 문장형 글을 임의로 전부 불릿으로 바꾸거나 짧은 메모를 불필요한 서론·결론으로 늘리지 않는다.
- `현황·문제·조치·다음 단계`처럼 내용에 필요한 구획만 둔다.

### 항목 계층

정식 공문서에서 항목을 둘 이상으로 나눌 때는 기관 양식을 우선한다. 별도 양식이 없으면 법령의 계층 `1. → 가. → 1) → 가) → (1) → (가) → ① → ㉮`를 따른다. `□·○·-·ㆍ`도 사용할 수 있지만 같은 깊이에서 기호를 섞지 않는다.

`~함·~음·~임`을 일본어 잔재라는 이유만으로 고치지 않는다. 국립국어원은 그 기원을 확인할 수 없다고 답했다. 독자, 문서 유형, 기관 문체와 문장 완결성을 기준으로 판단한다.

최근 행정안전부의 AI 친화형 보고서 원칙처럼 특정 기관이 서술식 문장과 표준화된 항목 표시를 요구할 수 있다. 이를 모든 개조식 문서의 보편 규칙으로 확대하지 말고 최신 기관 지침을 확인한다.
